# Code of Conduct

## Our standard

This project is a small open source contract repository. Contributors are
expected to be respectful, direct, and technical. Specifically:

- Assume good faith in review comments; critique code, not people.
- Keep discussion in issues and pull requests so decisions stay searchable.
- No harassment, personal attacks, or discriminatory language.

## Scope

This applies to issues, pull requests, commit messages, and any other project
communication channel.

## Enforcement

Maintainers may edit, hide, or delete comments that violate this document, and
may block repeat offenders from the repository. Report concerns through a
private message to the maintainer rather than a public issue.
